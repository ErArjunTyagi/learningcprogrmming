## 💡 Learning Philosophy

> **Don't just learn code. Learn how to think like a programmer.**

For every problem, I try to understand:

1. What is the problem?
2. What is the input?
3. What should the output be?
4. What logic can solve it?
5. Can the solution be improved?
6. What did I learn from the problem?

This repository is therefore not just a collection of programs — it is a record of my **programming journey and improvement over time.**
